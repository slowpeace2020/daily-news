Netflix Tech Blog 2026-06 · 最新

How Netflix Simplified Batch Compute with Kueue

Netflix 将云原生批量任务队列系统 Kueue 集成到其容器平台 Titus，彻底替代了内部自研的 CMB（Compute Managed Batch）系统。Kueue 提供开箱即用的多租户配额管理、抢占调度（preemption）、全量或全无调度（all-or-nothing）以及拓扑感知调度等特性，这些都是 Netflix 此前需要在 CMB 中手动实现的。整个迁移过程对业务方完全透明，用户零改动，容器启动速率与最大吞吐量均无回退——这是一次将自研复杂度向云原生生态迁移的工程典范。

Python 3.15 Hits Feature Freeze and Other News for June 2026

Python 3.15 正式进入 Feature Freeze，Beta 2 已发布，Release Candidate 阶段将于 8 月 4 日开放，正式版预计秋季推出。本月最值得关注的是 PEP 831（Frame Pointers Everywhere）获批 Final 状态，CPython 将默认开启 frame pointer 编译，使性能分析器（profiler）和可观测性工具能够生成准确的调用栈——这对生产环境性能排查意义重大。此外 PEP 808（在动态元数据中包含静态值）也已获批，弥补了 pyproject.toml 在配置灵活性上的短板。

The Go Blog 2026-06 · 最新

Go 1.27 Release Candidate 1 发布 — Generic Methods 正式落地

Go 团队发布了 Go 1.27 的第一个 Release Candidate，邀请开发者在生产负载和单元测试中进行实测并反馈。Go 1.27 最重磅的特性是 Generic Methods（泛型方法）的正式支持：开发者现在可以在特定类型的命名空间内定义泛型函数，不再需要将其提升为包级别的泛型函数，大幅改善了泛型代码的组织方式。正式版预计 2026 年 8 月发布，可通过官方下载页或 go install 命令体验。

📹 Backend Engineering Show — PostgreSQL 吞吐量在 Linux 7.0 内核上骤降 50% 的根因分析

Hussein 在本期 Backend Engineering Show 中详细复盘了一位 AWS 工程师发现的严重性能回归：在 Linux 7.0 内核上，PostgreSQL 的吞吐量下降了 50%。根因分析指向 Linux 7.0 引发的大量 TLB（Translation Lookaside Buffer）未命中和 page fault，而 PostgreSQL 基于多进程（process-based）而非多线程的架构设计显著放大了这一问题。这是一个将内核级别内存管理变更、数据库架构设计与性能调优结合在一起的极佳案例学习。
