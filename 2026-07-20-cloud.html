Issue #524：Airbnb 的 Sitar-agent——Kubernetes 中跨万级 Pod 的动态配置 Sidecar

SRE Weekly #524（2026-07-05）重点推荐 Airbnb 工程团队发表的 Sitar-agent 实践——这是一个部署在 Kubernetes Pod 内的动态配置 Sidecar，负责跨数万个 Pod 每分钟多次交付配置更新。Sitar-agent 通过共享文件系统与内存缓存在本地提供配置数据，最新重构引入 Java 重写、Amazon S3 快照引导机制，并将存储层从 Sparkey 迁移至 SQLite，显著提升启动性能与配置可用性。该方案统一了 Java、Python、Go、TypeScript、Ruby 等多语言服务的配置下发逻辑，将配置分发复杂度封装于单一 Sidecar 组件，是 Kubernetes 平台大规模运维实践的典型参考。
