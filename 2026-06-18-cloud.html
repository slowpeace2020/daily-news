EP217：Latency vs Throughput vs Bandwidth——三者的本质区别与实践影响 Jun 6, 2026

ByteByteGo 最新一期系统设计文章清晰拆解了三个常被混淆的性能指标：Latency（延迟）是单个数据包从发送方到接收方所需的时间；Throughput（吞吐量）是单位时间内实际成功传输的数据量；Bandwidth（带宽）则是链路的最大理论容量上限。文章用"高速公路"类比形象说明：带宽是车道宽度，吞吐量是实际车流量，延迟是从 A 点到 B 点的行驶时间。三者相互独立但又相互影响——网络拥塞、丢包和协议开销会压低吞吐量，使其始终低于带宽；低延迟也并不等于高吞吐量。理解这三者对于 SRE 做性能瓶颈定位至关重要。

Agentic Code Review：AI 正在重新定义代码审查的核心技能 Jun 16, 2026

TLDR Tech 6 月 16 日期报道了 Agentic Code Review 的新趋势。对 33,707 个 Agent 生成 PR 的研究发现，AI 擅长处理小型、边界清晰的改动（约 28% 几乎立即被合并），但面对主观性反馈时往往放弃迭代。研究者提出"断路器（circuit breaker）"方案：在人工介入前，通过文件类型、Patch 大小等廉价信号预测高维护成本的 PR，从而在早期分流，避免工程师在 Agent 会抛弃的大型改动上投入大量精力。这意味着 Code Review 的核心能力已从"检查眼前的逻辑"转变为"重建没有被写下来的意图"——后者更难，也更慢。
