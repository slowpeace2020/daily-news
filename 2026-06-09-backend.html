Scaling ArchUnit with Nebula ArchRules

Netflix 采用 polyrepo 策略管理数以万计的 Java 仓库，原生 ArchUnit 只适用于单仓库的 JUnit 测试套件，无法跨仓库共享架构规则。Nebula ArchRules 通过两个 Gradle 插件（Library Plugin 与 Runner Plugin）解决了这一问题：Library Plugin 让团队将规则打包为独立制品，Runner Plugin 负责在任意仓库中执行这些规则，实现架构约束的统一治理。Netflix 下一步计划结合 OpenRewrite（确定性修复）和 LLM（非确定性修复）探索自动化修复，将架构违规从"发现"推进到"自愈"。
