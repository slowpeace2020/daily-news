Netflix Tech Blog — 工程实践

Scaling ArchUnit with Nebula ArchRules — 跨万级仓库共享架构规则

Netflix 采用 polyrepo 策略管理数万个 Java 仓库，原生 ArchUnit 仅支持单仓库内的架构规则校验。为此 Netflix 开源了 Nebula ArchRules Gradle 插件，允许团队将架构规则封装为可复用库，并在任意数量的仓库中一键应用，既支持 OSS 规则库也支持私有内部库。

插件分为两部分：ArchRules Library Plugin（用于定义规则并实现 ArchRulesService 接口）与 ArchRules Runner Plugin（用于在目标仓库执行规则）。未来计划整合自动修复（auto-remediation）能力，进一步降低架构债务治理成本。
