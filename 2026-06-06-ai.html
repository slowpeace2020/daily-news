Anthropic Blog

Claude Opus 4.8 发布 & Expanding Project Glasswing

Anthropic 于 5 月 28 日发布 Claude Opus 4.8，引入 dynamic workflows（动态工作流）功能，使 Claude Code 能够一键完成跨数十万行代码的大规模迁移，并以现有测试套件作为验收标准；新模型 agentic 编码评分从 64.3% 提升至 69.2%，同时带来 effort control（精力控制）与中途注入 system message 等 API 新特性。6 月 2 日，公司还宣布 Project Glasswing 扩展至约 150 个新非营利组织，为其提供免费或优惠的 Claude 访问权限，推动 AI 惠益更广泛分配。

Codex for Every Role, Tool, and Workflow

OpenAI 于 6 月 2 日宣布 Codex 全面覆盖各类角色、工具链与工作流，标志着 AI 编程辅助向纵深落地迈出重要一步。同日 Frontier 模型与 Codex 上线 AWS，进一步扩大企业级可用范围。此外，GPT-5.5 Instant 已于 5 月 5 日面向所有免费用户开放，取代 GPT-5.3 Instant 成为 ChatGPT 默认模型，将顶级推理能力普惠化落地。

Google DeepMind Blog

Introducing Gemma 3n: The Developer Guide

Google DeepMind 于 6 月 3 日发布 Gemma 3n 开发者指南。该模型采用 MatFormer（Matryoshka Transformer）嵌套弹性架构，原生支持图像、音频、视频与文本多模态输入，专为端侧部署优化——E2B/E4B 型号实际参数量为 5B/8B，但通过 Per-Layer Embeddings（PLE）等技术，运行内存仅需 2GB/3GB。Gemma 3n 可无缝接入 Hugging Face Transformers、Ollama、MLX 等主流生态，是目前性能最强的移动端开源多模态模型之一。

Hugging Face Blog

Nemotron 3 Nano — A New Standard for Efficient, Open & Intelligent Agentic Models

NVIDIA 于 6 月 4 日在 Hugging Face 发布 Nemotron 3 Nano，这是面向 Agent 场景设计的高效开源模型家族，采用 Mamba-Transformer MoE 混合架构，支持 100 万 token 超长上下文。旗舰版 Nemotron 3 Nano Omni 同时具备图像、音频、视频理解与 GUI 计算机操控能力（computer use），在多模态 Agent 任务上相比同类模型可实现最高 9× 吞吐量提升，BF16/FP8/NVFP4 权重全部开源上传至 Hugging Face。

The Rise of the AI Forward Deployed Engineer

5 月 29 日一期 The Batch 深度聚焦「AI 前线部署工程师」（AI Forward Deployed Engineer, FDE）这一新兴职位：此类工程师嵌入客户组织内部，专职构建和调优 agentic 工作流，将业务需求直接落地为 AI 解决方案。FDE 的兴起折射出行业范式的转变——企业的核心需求已从"通用工具平台"演进为"定制化 Agent 交付能力"，这对 AI 工程师的产品感知与全栈整合能力提出了更高要求。

The Devin is in the Details — Background Agents with Cognition's Walden Yan

5 月 28 日最新一期邀请 Cognition（Devin 背后公司）联合创始人兼 CPO Walden Yan，深入探讨 background agent 系统的架构设计、记忆管理、测试策略与多 Agent 协作动态。节目指出，自 2025 年 12 月 Opus 4.5、GPT-5.2 等模型能力跃升以来，行业正快速从"手把手引导模型"迁移向更自主的驾驶模式，Shopify、Stripe、Ramp 等企业纷纷自建内部编程 Agent——独立 coding agent 平台面临的竞争压力正在加剧。
